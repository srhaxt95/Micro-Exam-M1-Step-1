เครื่องมือเจาะลึกการทำงานโค้ดไฟวิ่ง (LED Pattern Inspector)

จำลองฮาร์ดแวร์จริง พร้อมถอดรหัสฟังก์ชันการทำงานทีละบรรทัดตามโจทย์ข้อ 1

1. จำลองหลอดไฟบนบอร์ดจริง

D0 (แดง) Pin 13
D1 (ส้ม) Pin 12
D2 (เหลือง) Pin 11
D3 (เขียว) Pin 10
กำลังทำงาน: Step 0

2. ตัวติดตามการทำงานของโค้ด (Live Code & Function Inspector)

const int ledPins[4] = {13, 12, 11, 10}; const int pattern[9][4] = { ... }; void setup() {   pinMode(ledPins[i], OUTPUT);   digitalWrite(ledPins[i], LOW); } void loop() {   for (int step = 0; step < 9; step++) {     digitalWrite(ledPins[pin], pattern[step][pin]);     delay(300);   } }
คำอธิบายจังหวะปัจจุบัน
กำลังเตรียมความพร้อมของระบบ...

3. สรุปความหมายของตัวแปรและฟังก์ชันสำคัญ

1. const int ledPins[4]

คืออะไร: อาร์เรย์ (Array) ขนาด 4 ช่อง ใช้เก็บตัวเลขขาของไมโครคอนโทรลเลอร์
หมายถึงยังไง: เป็นการผูกตัวแปรเข้ากับฮาร์ดแวร์จริง เช่น ช่องที่ 0 คือขา 13 (LED แดง), ช่องที่ 3 คือขา 10 (LED เขียว) ทำให้เวลาสั่งงานไม่ต้องพิมพ์เลขขาซ้ำ ๆ แค่เรียกผ่านดัชนี ledPins[i]

2. void setup()

คืออะไร: ฟังก์ชันเริ่มต้นการทำงานของ Arduino
หมายถึงยังไง: คำสั่งที่เขียนในนี้จะถูกเรียกทำงาน "เพียงรอบเดียวตอนเปิดเครื่อง" เหมาะสำหรับเตรียมความพร้อม เช่น สั่ง pinMode(..., OUTPUT) เพื่อสั่งให้ขาเป็นตัวปล่อยกระแสไฟออกไปหา LED

3. void loop()

คืออะไร: ฟังก์ชันลูปหลักของการประมวลผล
หมายถึงยังไง: เมื่อทำคำสั่งบรรทัดสุดท้ายในฟังก์ชันนี้เสร็จ ไมโครคอนโทรลเลอร์จะกระโดดกลับมาบรรทัดแรกของ loop() เพื่อทำใหม่เรื่อย ๆ ไม่มีวันหยุด (ตรงกับเงื่อนไขคำว่า Forever ในโจทย์)

4. digitalWrite(pin, value)

คืออะไร: ฟังก์ชันสั่งจ่ายหรือไม่จ่ายแรงดันไฟฟ้า (5V หรือ 0V)
หมายถึงยังไง: ถ้าค่าเป็น 1 (HIGH) บอร์ดจะปล่อยไฟ 5V ทำให้ LED สว่างขึ้น แต่ถ้าเป็น 0 (LOW) บอร์ดจะตัดไฟ ทำให้ LED ดับ

5. delay(300)

คืออะไร: ฟังก์ชันสั่งหยุดรอเวลา มีหน่วยเป็นมิลลิวินาที (ms)
หมายถึงยังไง: ตัวประมวลผลจะค้างสถานะไฟปัจจุบันไว้ 300 ms (0.3 วินาที) เพื่อให้สายตามนุษย์มองเห็นการกะพริบ/การวิ่งทัน หากไม่มีคำสั่งนี้ ไฟจะวิ่งเร็วหลายล้านรอบต่อวินาทีจนเห็นเป็นไฟติดค้างทุกดวง
